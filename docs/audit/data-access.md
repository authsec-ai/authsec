The pattern is clear:
- The newer IGA, cloud, discovery, connector, RBAC (roles_scoped_bindings), agent-policy and resource-server code is consistently scoped. It either has `workspace_id` in every predicate or loads the parent with a workspace filter first.
- Almost all the problems sit in the legacy user-flow ("uflow") stack:
  - `database/*` repositories;
  - `controllers/admin/{groups,sync_config,admin_sync,admin_invite,membership,admin_user}`;
  - `handlers/*webauthn*`;
  - `oidc_controller`, `workspace_admin_controller`, `enduser_auth_controller`.
- And in a few platform-global objects that are reachable by any workspace admin: `workspaces`, `oidc_providers`, `trusted_issuers`, `services` (extsvc), migrations, and oocmgr.
